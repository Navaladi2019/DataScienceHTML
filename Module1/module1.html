Python distribution and package managers

1. Anaconda

There are multiple ways to install Python. The suggested one is to install Anaconda distribution, which comes with a set of pre-installed libraries for data science. To learn more and install Anaconda distribution go through this page (recommended). 

Although it's a good go-to option for newcomers, one can prefer to install miniconda distribution and all needed packages themselves. To install more light-weighted Miniconda distribution you need this page

2. Pip

Data Science comes with many packages. The most popular way to install everything is via pip. Basic usage of it can be found here﻿

﻿

3. Conda

Most data science packages can be installed via pip. However, some of them can have external Java, C, or other dependencies. While pip is a Python package manager, conda is a package manager for everything and so can be used to install all needed dependencies.

To learn more about conda and how to use it look at this official tutorial or this which is a bit more comprehensive.

[optional] If you want to learn more about pip and conda differences, look at this page on the topic.

﻿

4. Broader overview: conda, pipenv, venv

Conda is not the only tool to control and configure Python environments. Some alternatives can be represented by pipenv and venv.

The reason why Data Scientists could choose either pipenv or venv over conda is lightweightness.

Data and domain introduction

When you only start working with some data, you might be not very familiar with the domain this data came from.

  • What kind of relations might be meaningful to search for?
  • What statistical tests are applicable here?
  • What kind of distances make sense in this domain?

So, when you start with exploratory data analysis it is a very good practice to do an introduction of the data you are working with.

Examples of the notebook with good domain introduction (please, pay attention here, notebooks below are given only for demonstration of good data and domain introduction and description, no need to spend too much time on them): kaggle 1, kaggle 2.

Data types: continuous, discrete, ordinal, nominal

Data usually contain some number of features, something we know about objects in our domain. These features might be different in terms of their quality/quantity properties.

For example, there is a difference between education and body weight, because the first feature might have only a few options, whereas the second one might have hundreds or even thousands of unique values, depending on the precision of measurements.   

This is a very important topic that needs to be taken seriously, because it directly affects the choice of pre-processing method, statistical tests, visualizations, etc.
